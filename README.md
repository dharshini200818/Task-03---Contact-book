Task 03 - Contact Book

About the Project: 
This is a simple contact book made using Python. It allows users to store and manage
contact details like name, phone number, and email address. The program has a menu that
lets users add, view, search, edit, and delete contacts.
The contacts are stored in a JSON file, so the saved details are available even after
closing and running the program again. The search option can also find contacts by matching
only part of a name. If the JSON file is missing or contains invalid data, the program
starts with an empty contact list.

Features:

- Add new contacts with name, phone number, and email.
- View all saved contacts.
- Search for contacts using a full or partial name.
- Edit existing contact details.
- Delete contacts after confirmation.
- Save contact details in a JSON file.
- Handle missing or invalid JSON files.

Requirements:

- Python 3
- Visual Studio Code or any Python-compatible editor

How to Run:

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal in that folder.
4. Run the program using: python task_3.py
5. Select an option from the menu and follow the instructions.

Files Used:

task_3.py - Contains the Python code for the contact book.
contacts.json - Stores the contact details and is created when contacts are saved.

Learning outcome: 

While working on this project, I practised using Python functions, lists, dictionaries,
loops, and conditional statements. I also learned how to read and write JSON files and 
handle errors when a file is missing or contains invalid data.
